# Recursor 0.2.1

Syntax trees have a new design, and the resource page opens with a description
and an image.

- `RecursorProgramTree[program]` draws each node as a named box colored by
  kind: loops, arithmetic, choice and binding, or inputs and constants. The
  layout keeps boxes apart, and the picture is as wide as its tree, so names
  have the same size in every tree. The result is still a graph that accepts
  TreeGraph options. A layout, root, labels or vertex shapes of your choosing
  give the earlier TreeGraph drawing.
- The resource page describes the language beside an image computed from
  the paclet and the OEIS experiment. `make hero` redraws the image from
  `docs/Hero.wl`.
- A release now starts from a pushed version tag. Successful CI on main no
  longer publishes by itself.

The language and the results of its functions are otherwise unchanged from
0.2.0. Includes 67 documentation pages. Requires Wolfram Language 15.0 or later. Released under
the MIT license.

The release contains the paclet, SHA-256 checksums, build provenance and the
PacletPage documentation build. Publication reuses the archive verified by CI.
