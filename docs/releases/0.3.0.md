# Recursor 0.3.0

The synthesizer finds more programs and says when to believe them, evolution
can be guided by the examples, and programs translate to Wolfram Language.

- `SynthesizeRecursor` composes programs from sums, products and counts over
  a loop index. It finds them alone, and inside the n-th number with a
  property, the count of such numbers, partial sums, differences and a program
  applied to a function of the input. Two enumerated parts are joined at the
  root. Primes, composites, the number of divisors and the prime-counting
  function are now found from their terms.
- Solved has a new meaning. The search keeps a quarter of the examples aside,
  and a program is solved when it reproduces them, there are at least four of
  them, and the examples hold enough information to rule out a chance fit.
  The result reports TrainingExamples, HeldOutExamples, HeldOutMatches and
  Evidence. A program that fits without that evidence is still returned. The
  options "HoldOut", "RequiredEvidence" and "MaxFoldTerm" are new.
- `EvolveRecursor[examples, Method -> "Guided"]` chooses each variation from
  the values the examples require. It runs a parent backwards to the values
  one of its parts must have and takes that part from a library of small
  programs; it also evolves recurrence steps. With the budget of the corpus
  experiment it fits most sequences and predicts seven times as many as the
  default method, which is unchanged. The option "LibraryCost" is new.
- A search is written as array arithmetic and frees its memory when it ends.
  It takes about two seconds where it took five, and repeated searches no
  longer grow the kernel. `EvolveRecursor` frees its memory too.
- `TranslateRecursor[program]` gives a Wolfram Language function with the
  values of a program. Loops become sums, products, counts and searches where
  that keeps the values, and some results are recognized as built-in
  functions.

Results of `SynthesizeRecursor` that relied on Solved meaning a fit to the
examples change: test `! MissingQ[result["Program"]]` for a fit. On 3,000
sequences of the OEIS snapshot that were not used to set the method, 248 of
the 252 programs solved from twenty terms reproduced every later term on
record; from sixteen terms it was 62 of 65.
[The measurements](../notes/OEISSynthesisAndEvolution.md) give the details.
Includes 68 documentation pages. Requires Wolfram Language 15.0 or later.
Released under the MIT license.

The formal theorems concern their specified models. A solved program is strong
evidence for a rule, not a proof of it. A translation is tested on inputs, not
proved equal to its program.

The release contains the paclet, SHA-256 checksums, build provenance and the
PacletPage documentation build. Publication reuses the archive verified by CI.
